# Dermatology Disease Data Analysis

## Project Overview
This project analyzes a dermatology dataset using Python for data exploration and visualization.

The goal of the project is to:
- Understand medical dataset structures
- Identify missing or unusual data
- Visualize disease-related patterns
- Practice beginner-friendly data science techniques

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Features
- Dataset loading and cleaning
- Statistical summaries
- Correlation heatmaps
- Histograms
- Disease class distribution charts
- Boxplot analysis

## Project Structure

├── dermatology_database_1.csv
├── analysis.py
├── README.md
